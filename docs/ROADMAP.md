# Roadmap

These are proposed priorities, not shipped features or release commitments.

| Priority | Work | Completion evidence |
|---|---|---|
| First run | Reproducible fixture setup and readable failure messages | A fresh checkout reaches Review without model or Instagram credentials |
| Source quality | Expired-date, conflicting-source and booking-condition fixtures | Expected inclusion/exclusion decisions are documented and tested |
| Public experience | Separate participant submission from operator approval | Participants cannot publish, delete or access other sessions |
| Policy evidence | Versioned probes and visible effective policy | Each allow/deny result links to the policy and execution environment |
| Publishing reliability | Retry and duplicate-post behavior | A failed or repeated request cannot silently create duplicate public posts |
| Discovery | Better event coverage and publication freshness | Output identifies retrieval date, event date and source, with a refresh process |

Follow [Issues](https://github.com/juyoungml/nemo-k-cards/issues) for specific work. A useful report includes the observed behavior, expected behavior and a reproducible input.
