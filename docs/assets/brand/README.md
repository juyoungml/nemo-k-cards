# Nemo K Cards identity

The mark combines a stack of rectangular cards with the red and blue already used by the Admin identity. The small circular opening and text lines make it read as a publishing mark without reusing Instagram's or NVIDIA's logo.

- `logo-light.svg` / `logo-dark.svg`: compact, transparent mark.
- `wordmark-light.svg` / `wordmark-dark.svg`: horizontal identity.
- `hero-light.svg` / `hero-dark.svg`: README headers with solid light/dark backgrounds.
- `logo-512.png`: raster profile/avatar asset.
- `social-preview.png`: 1280 × 640 link-preview artwork, ready to upload in repository Settings → Social preview.

Use the light assets on light backgrounds and dark assets on dark backgrounds. Keep the mark's proportions and surrounding space. Color values match [DESIGN.md](../../../DESIGN.md): ink `#111418`, Seoul red `#E4002B`, mark red `#CD2E3A`, mark blue `#0047A0`.

The original SVGs are editable and available under the repository's MIT license. This identity does not change the existing app or card styles.
