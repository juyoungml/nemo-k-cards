## 배포 설정과 공개 범위

- 백엔드를 외부에 노출할 때 `ADMIN_TOKEN`을 설정해야 합니다. 기본값이 비어 있으면 API 인증이 적용되지 않습니다.
- `/health`와 `/assets/`는 인증 예외입니다. 생성된 이미지에 공개할 수 없는 정보를 넣지 않아야 합니다.
- 실제 Instagram 게시를 검증하기 위해 운영 게시물을 생성하지 않았습니다. 공개 Admin의 mock 화면 확인과 코드 검토까지 수행했습니다.
- 폰트의 고지 파일과 발표 자료의 출처 목록은 저장소에 포함돼 있습니다. 저장소 전체에 적용하는 LICENSE는 아직 없어 이번 변경에서 임의로 추가하지 않았습니다.
