# Source material counts as verified

Every fact on a Deck is normally verified against links the host checks itself, and Guide facts must trace to an official source. Facts taken from an Organization's own Source material (its press release, page or notice) skip independent checking: the Organization vouches for its own information, it is often the only source (an unannounced closure, an exhibition not yet online), and refusing it would make the product useless for announcements. Decided 2026-10-29.

## Consequences

- Each fact keeps where it came from, so a slide can show "from your material" versus a checked link (story 2).
- Research still adds practical details (getting there, prices for foreigners), and those are verified normally.
- Material that contradicts a checked public source raises an Issue for a person to decide; it is never silently preferred or dropped.
