Nemo K Cards — 발표 노트
본문 6분 20초 / 화면 전환·여유 40초
페이지 번호는 표지 포함 PDF 기준입니다. 장표 번호는 01–08입니다.

1. 표지 0:00–0:20
한국 생활·여행 정보를 영어 카드뉴스로 전하는 Nemo K Cards입니다. 자료로 만든 내용을 사람이 확인하고 수정한 뒤, 승인한 버전을 Instagram에 게시하도록 연결했습니다.

2. 서비스 소개 0:20–0:45
콘텐츠를 만드는 에이전트와 독자가 만나는 Instagram 계정으로 나뉩니다. 운영자는 Admin에서 작업하고, 독자는 익숙한 Instagram에서 생활·여행 정보를 발견합니다. 제작 에이전트의 권한은 NVIDIA OpenShell로 제한합니다.

3. 여행자의 질문 0:45–1:20
한 사람은 방문 시기에 열리는 팝업과 행사를 어디서 찾는지 묻습니다. 다른 사람은 처음 한국에 와서 기후동행카드를 어디서 사는지, 현금은 얼마나 필요한지 묻습니다. 화면 오른쪽은 사용자가 제공한 실제 Reddit 원문 캡처입니다. 행사 탐색과 교통·결제 이용 안내 모두 필요한 정보를 이해하는 어려움이 있습니다. 개별 사례라는 범위는 유지합니다.

4. 조사 근거 1:20–1:55
관광 정보와 안내가 불편 사례의 16.4%였습니다. 전체 여행자의 불만율이 아니라 분석된 불편 사례의 구성비입니다. 교통은 13.1%, 결제는 12.0%입니다. 통계는 여행 관련 불편 사례를 분석한 것이며 전체 거주자 통계로 확대하지 않습니다. 행사 정보에서 교통·결제 이용 안내까지 이해를 돕는 카드로 확장하려고 합니다. 결제나 본인 인증 기능 자체를 바꾸는 것은 별도 과제입니다.

5. 공식 자료 조사부터 카드 제작·승인까지 1:55–3:25
인천공항에 도착해서 기후동행카드를 어디서 사는지 영어 카드로 알려 달라고 요청합니다. 에이전트가 공식 자료를 찾아 이용 조건과 구매 안내를 교차 확인하는 흐름입니다. 왼쪽은 사용자가 제공한 실제 한국어·영어 공식 자료 캡처이고, 가운데는 직접 제작한 카드 시안입니다. 공항 이동은 별도 요금이고 카드는 서울역 지하철 구역에서 구매하며, 단기권은 충전일부터 시작한다는 내용을 정리했습니다. 운영자가 검수하고 안전검사를 통과한 버전을 승인하면 백엔드가 게시합니다. 이 장표는 과정을 설명하는 시안이며 실제 자동 생성·게시 실행 결과는 아닙니다.

6. 게시 전 검수 3:25–4:30
날짜와 장소 같은 사실마다 출처를 확인합니다. 출처 없는 정보나 사람이 바꾼 문구도 구분합니다. 오른쪽은 사람이 수정한 내용을 다시 검사하는 흐름입니다. 텍스트와 이미지를 확인해 문제 이유와 수정안을 안내하며, 차단된 버전은 승인할 수 없습니다. 왼쪽은 원본 발표의 기존 Admin 검수 화면이며 시연용 데이터입니다. 오른쪽 설명은 현재 구현 기준이고, 캡처 자체에 새 기능이 모두 보이는 것은 아닙니다. 추후 새 화면으로 교체할 예정입니다.

7. OpenShell 정책 4:30–5:15
콘텐츠 안전검사와 실행 권한 제어는 역할이 다릅니다. 외부 자료에 삭제하라는 악성 지시가 섞여 있더라도 에이전트가 할 수 있는 행동을 정책으로 제한합니다. 조회 요청과 게시·삭제 권한을 분리합니다. 이 장의 시나리오는 정책 설계이며 실제 거부 로그와 구분해 설명합니다.

8. Policy Log 5:15–5:45
기존 테스트 요청의 거부 기록을 보여줍니다. 이 기록은 해당 요청이 거부됐다는 증거이고, 모든 공격을 차단했다거나 모델이 실제 악성 지시를 따랐다는 의미는 아닙니다.

9. 실행 구조와 마무리 5:45–6:20
Brev 실행 환경에서 OpenShell이 Claude Code의 파일과 네트워크 권한을 제한합니다. 백엔드는 출처·렌더링·안전검사와 버전을 관리합니다. 게시 토큰은 Vault에 두고 백엔드만 사용합니다. 제작은 위임하면서, 근거 확인과 공개 계정의 통제를 운영자에게 남기는 것이 핵심입니다.
